# Assets setup — read before running

## Exact placement

The project expects one folder named `assets` directly beside `index.html`:

```text
Ali_Haider_Portfolio_Editable_Source/
├── index.html
├── styles.css
├── script.js
├── projects.json
├── assets/                 <-- copy the original folder here
│   ├── Ali-Haider-CV.pdf
│   ├── hero-animation/
│   ├── images/
│   ├── posters/
│   └── videos/
├── colors/
├── spacing/
├── typography/
├── components/
├── styles/
└── text-content/
```

## How to restore your assets

1. Open your original reference ZIP.
2. Navigate into `Ali_Haider_Portfolio_Refined_v2/fial port woasset/`.
3. Copy the complete `assets` folder found inside that directory.
4. Paste it beside `index.html` in this source project. Replace the lightweight placeholder `assets` folder or merge its contents.
5. Do not rename files or subfolders. Paths are relative and preserve original capitalization, spaces and punctuation.

## Important paths used by this website

- CV: `assets/Ali-Haider-CV.pdf`
- Hero artwork: `assets/hero-animation/`
- Portfolio imagery: `assets/images/`
- Project thumbnails: `assets/posters/`
- Original video archive: `assets/videos/`
- Category video showcase: `assets/videos/category-work/`

The showcase configuration references 18 original videos across six categories. Those 18 paths were checked against the supplied original ZIP and all were found. This check verifies that the files exist in the reference archive; it does not claim that playback was browser-tested in this session.

If you use a different asset backup, verify the exact spelling and capitalization of every referenced file. Windows is often case-insensitive, but many web hosting servers are case-sensitive.

# Website text and showcase content

- `skill-showcases.json` controls the new skill showcase section: field headings, short descriptions, capability bullet points, video titles and video paths. Edit this file to update those new showcase panels without changing JavaScript.
- The original portfolio's existing copy remains in `index.html` to preserve its original structure and avoid a risky full rewrite. Use your code editor's Find feature to locate the heading or sentence you want to change.
- Keep JSON syntax valid: use double quotes around keys and text, commas between items, and do not add a comma after the final item.

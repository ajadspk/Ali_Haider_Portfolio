# Original assets go here

This is a lightweight placeholder. It intentionally does not contain your large photographs or videos.

Copy the complete original `assets` folder from your reference project into this project root, replacing/merging this placeholder folder. Keep all original filenames and subfolders unchanged.

Expected examples:
- `assets/Ali-Haider-CV.pdf`
- `assets/hero-animation/`
- `assets/images/`
- `assets/posters/`
- `assets/videos/category-work/`

The project uses relative paths beginning with `assets/`.
